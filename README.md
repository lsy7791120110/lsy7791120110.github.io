## Publish
1. Create a public repository named `lsy7791120110.github.io` in account `lsy7791120110`.
2. Upload the contents of this folder, retaining its directories, to the main branch.
3. In Settings > Pages select Deploy from a branch, main, / (root), then Save.

and existing owner management remain on the original site. Turning it ON there will
not automatically add a link to this export. Integration requires a later update.
