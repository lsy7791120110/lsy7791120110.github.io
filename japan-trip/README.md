# 일본 여행 노트

후쿠오카·삿포로·오사카·도쿄 여행을 준비하는 정적 웹앱입니다.

## 사용하기

도시를 선택하고 기본 장소의 하트를 누르거나 직접 장소를 추가합니다. 저장한 곳을 날짜별 일정에 넣고, 순서와 방문 시각을 수정할 수 있습니다. 장소별 Google 지도 및 구간별 도보·대중교통·차량 길찾기, 체크리스트, 메모, 엔화 지출과 직접 입력한 환율을 이용한 원화 환산을 지원합니다.

기본 장소 24곳은 탐색 후보입니다. 사용자가 저장한 위시리스트나 확정 일정이 아닙니다. 기본 일정은 날짜 미정·3일 구성이며 각 도시 설정에서 변경할 수 있습니다.

## 저장과 백업

입력 내용은 이 브라우저의 localStorage에 저장됩니다. 로그인이나 서버 데이터베이스를 사용하지 않습니다. 다른 기기로 기록을 옮기려면 **백업**을 다운로드한 뒤 다른 기기에서 **가져오기**를 누릅니다. 링크 공유만으로 각자의 기록이 동기화되지는 않습니다. 가져오기 전 상태는 해당 브라우저에서 한 번 되돌릴 수 있습니다.

## 지도·정보

장소 지도는 Google Maps 검색 임베드를 사용하며, 이동시간은 Google Maps에서 확인합니다. 경로는 입력한 방문 순서를 따르며 자동 동선 최적화를 제공하지 않습니다. 긴 도보 일정은 모바일 경유지 한도를 고려해 나누어 연결합니다. 실시간 환율, 지도 저장 목록 동기화, 예약·결제를 실행하는 기능은 없습니다.

24개 기본 장소는 관광청 또는 시설의 공식 안내를 기준으로 2026-11-04 정리했습니다. 공식 안내 링크와 사진 라이선스는 앱의 출처 화면 및 data.js에서 확인할 수 있습니다. 사진은 Wikimedia Commons 원저작자의 CC 라이선스에 따라 표시하며, 카드 비율에 맞춘 화면상 자르기가 적용됩니다. 서체는 S-Core Dream입니다.

## 구성

- index.html: 앱 화면 구조
- style.css: 데스크톱·모바일 레이아웃
- app.js: 화면·입력·편집 동작
- core.mjs: 저장 데이터 검증·백업·날짜·지도 URL 함수
- data.js: 도시·공식 장소 정보·사진 출처

빌드나 API 키 없이 정적 파일을 GitHub Pages에서 제공합니다.
